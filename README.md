# Layer Studio · G-code 打印生长动画工作室

> 把拓竹 Bambu Studio 切片的 G-code 渲染成逼真的多色 3D 打印生长动画，导出最高 4K、30fps 的无水印视频。完全在浏览器本地运行，不上传任何文件。

![badge](https://img.shields.io/badge/tech-Vite%20%7C%20Three.js%20%7C%20WebCodecs-orange) ![badge](https://img.shields.io/badge/tests-31-green)

## 功能特性

- **真实挤出几何**：按 G-code 解析挤出路径，连续扁圆截面网格，转角 miter 焊接；精度分草稿 / 低 / 中 / 高 / 超精细，自动档按文件规模选择
- **回抽点（接缝凸点）**：识别外墙回抽位置，渲染成和耗材同色的小球，可开关、可调大小，也能改成切片软件那种标记点；随打印进度逐个出现
- **多色打印**：解析 T 换色指令与 FLUSH / WIPE 宏，还原多色耗材与擦料塔
- **拓竹纹理 PEI 打印板**：磨砂凸起颗粒（按像素尺寸自动带限，远看变成粗糙度，近看是颗粒，不产生摩尔纹）、斜边、中间 Logo；金色 / 深色 / 光滑 / 冷灰几种款式
- **4 个场景预设**：柔光影棚、创客工作台（A2 绿色切割垫 + 木桌）、胡桃木书桌、暗场展台
- **电影级渲染**：Neutral 色调映射、面光源软阴影、GTAO 环境遮蔽、物理景深、暗角与抖动
- **多重采样抗锯齿**：亚像素抖动 + 高斯加权累积，预览静止时自动逐步精修；导出每帧 4 / 12 / 24 / 48 次采样，消除层纹摩尔纹
- **相机编排**：固定机位 / 缓慢环绕 / 环绕+随打印高度抬升 / 自定义关键帧
- **视频导出**：WebCodecs（Mediabunny）逐帧确定性编码，720p / 1080p / 1440p / 4K，MP4 / WebM 自动回退
- **大文件**：Worker 内解析，结果用可转移的 TypedArray 回传（不再出现 “Data cannot be cloned, out of memory”），路径自动简化，GPU 上传后释放 CPU 内存
- **场景保存/载入**：所有参数与相机关键帧可保存为 JSON

## 技术栈

| 模块 | 技术 |
|---|---|
| 构建 | Vite 7 |
| 3D 渲染 | Three.js 0.185（PMREM 环境、GTAO、UnrealBloom、自定义累积/呈现着色器） |
| 视频编码 | Mediabunny（WebCodecs 封装） |
| 解压 | fflate（3mf zip 解析） |
| 测试 | Node.js 内置 `node --test` |

## 快速开始

```bash
# 1. 安装依赖（首次需要联网）
npm install

# 2. 启动开发服务器
npm run dev
# 浏览器打开 http://127.0.0.1:5173/

# 3. 构建生产版本
npm run build

# 4. 运行测试（31 项，含真实 G-code 解析校验）
npm test
```

Windows 下也可双击 `启动工作室.bat` 一键启动。

## 使用流程

1. 点击 **打开切片文件** 加载 `.gcode` 或 `.3mf`，或点 **三色示例** 体验内置模型
2. 在 **场景** 区选择场景预设和背景
3. 调整耗材配色、表面材质、网格精度、打印板款式，打开或关闭 **回抽点**
4. 在灯光与画质区设置布光、曝光、阴影柔和度、辉光、暗角、景深
5. 选择相机运动模式，必要时保存关键帧
6. 选择分辨率、时长、抗锯齿档位，点击 **导出视频**

## 大文件建议

- 几百万段以上的文件会自动使用草稿精度。实测一个 87 MB 的 3MF（1346 层、700 多万段）加载约 50 秒，约 6000 万三角形
- 这种规模建议导出 1080p / 1440p、抗锯齿选“高”。4K + 电影档会非常慢
- 浏览器建议使用最新版 Chrome / Edge，并保证独立显卡可用

## 支持范围

- 解析 `G0` / `G1` 直线、`I/J` 圆心参数圆弧
- 回抽补偿与回抽点、换色 `T` 指令、`FLUSH` / `WIPE` 宏标记
- 自动识别层高、线宽、打印板尺寸
- 多色（AMS）打印件

## 已知限制

- 不支持未切片的 STL / 3MF 网格（仅支持切片后的 G-code）
- 不支持 `R` 半径参数的圆弧（目前仅支持 `I/J`，会报错提示）
- 生长动画的活动末段按整段显现，未做段内插值
- 高精度、4K 与高采样档位会显著增加显存占用和导出时间

## 项目结构

```
src/
  parser.js      G-code 解析（直线、圆弧、回抽点、换色、宏）、路径简化、Worker 传输打包
  beads.js       挤出网格生成（扁圆截面、miter 焊接、drawRange 生长）
  blobs.js       回抽点实例化网格
  plate.js       拓竹纹理 PEI 打印板（颗粒着色器、丝印贴花、斜边几何）
  scenes.js      场景预设、程序化地面、科幻底座、自定义环境光
  render.js      累积抗锯齿、软阴影、景深、辉光与呈现管线
  exporter.js    视频编码器探测与逐帧导出
  main.js        主界面、相机编排、交互
  worker.js      后台解析线程
  style.css
tests/           31 项自动测试
```
